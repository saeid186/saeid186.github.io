About

Description

I'm Saeid, a systems administrator from Tehran. I've been keeping Linux servers, networks and internal tools running for more than 14 years. For the last seven, most of my work has been in Atlassian tools, mainly Jira Server and Data Center.

A lot of my projects start with a simple question: why is someone still doing this by hand? The fix is usually a ScriptRunner listener, a small Python service or an Ansible playbook. I'd rather fix a process once than handle the same ticket fifty times.

I've been freelancing since April 2025, building Jira automation, CRM features and Django backends for a few companies. Before that I spent five and a half years at Mobinnet as Jira and systems administrator, and two and a half years at AsiaTech running RADIUS and AAA infrastructure.

I plan to move to Germany and will need visa sponsorship. If your team runs Jira Data Center and spends too much time on manual work, I'd be glad to talk.
